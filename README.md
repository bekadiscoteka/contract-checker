# Проверка договоров

Скрипт выделяет потенциально рискованные условия договора и создаёт HTML-отчёт. Это не юридическая консультация.

HTML-отчёт показывает фактически использованный LLM-провайдер без технических деталей и перечисляет каждый отобранный для рассмотрения фрагмент с его статусом: выявлен риск, риск не выявлен или фрагмент не оценён. Фрагменты формируются эвристически и не обязательно соответствуют нумерованным пунктам договора; неотобранный текст не считается проверенным.

При запуске CLI и Telegram-бот выводят в консоль настроенный провайдер; для каждого документа дополнительно записываются запрошенный и фактически использованный провайдер. Уровень логирования задаётся переменной `LOG_LEVEL` (по умолчанию `INFO`).

## Установка

Требуется Python 3.9 или новее.

```cmd
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Для семантического поиска при первом запуске будет загружена модель `sentence-transformers` с Hugging Face. Без неё анализ продолжит работать по ключевым словам.

## Проверка из командной строки

Только правила, без обращения к LLM:

```cmd
python contract_checker.py contract.pdf --provider rules -o report.html
```

Для работы с локальной Ollama установите Ollama, загрузите модель и запустите её сервис:

```cmd
ollama pull qwen3:4b
python contract_checker.py contract.pdf --provider ollama -o report.html
```

Модель можно поменять переменной `OLLAMA_MODEL`; адрес локального API — `OLLAMA_URL` (по умолчанию `http://127.0.0.1:11434`). Для Anthropic задайте `ANTHROPIC_API_KEY` и используйте `--provider anthropic`. По умолчанию скрипт использует локальные правила и не вызывает платный API.

Если PDF является сканом, для OCR дополнительно нужны установленные системные программы Tesseract и Poppler, а также языковой пакет Tesseract для русского (`rus`).

## Telegram-бот

Бот работает через long polling, открыт для любого пользователя в личных чатах, принимает PDF, DOCX и TXT не больше 18 МБ, возвращает HTML-отчёт и удаляет временные файлы после обработки. Групповые чаты игнорируются. По умолчанию используется режим `rules`; чтобы запускать анализ через Ollama, установите `LLM_PROVIDER=ollama`.

### 1. Загрузите и проверьте модель Ollama

Откройте новое окно Command Prompt или PowerShell и проверьте установку:

```cmd
ollama --version
```

Приложение запрашивает у Ollama JSON-ответ и проверяет его структуру самостоятельно. Если установленная версия Ollama сообщает об ошибке параметра `format`, обновите Ollama с [ollama.com/download](https://ollama.com/download), перезапустите приложение и откройте новое окно терминала.

Загрузите рекомендуемую стартовую модель (скачивание может занять несколько гигабайт):

```cmd
ollama pull qwen2.5:7b
```

Убедитесь, что модель появилась в списке. Если модель ещё не скачана, загрузите её командой `ollama pull qwen2.5:7b`:

```cmd
ollama list
ollama run qwen2.5:7b
```

Введите короткий вопрос в интерактивном приглашении Ollama, затем выйдите командой `/bye`. Оставьте Ollama запущенной. Если команда `ollama` не распознана, завершите и снова откройте терминал после установки Ollama; при необходимости перезагрузите Windows.

### 2. Создайте Telegram-бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте отображаемое имя и уникальное имя бота.
2. Скопируйте выданный токен и храните его как пароль. Не вставляйте его в код, README или Git.

### 3. Запустите бота

Откройте новое окно Command Prompt в папке проекта, активируйте окружение, задайте токен и включите Ollama:

```cmd
.venv\Scripts\activate
set TELEGRAM_BOT_TOKEN=полученный_токен
set LLM_PROVIDER=ollama
set OLLAMA_MODEL=qwen2.5:7b
python telegram_bot.py
```

Переменные нужно задать в том же окне Command Prompt, из которого запускается бот; после изменения переменных остановите и запустите бот заново. Для CLI `--provider ollama` явно выбирает Ollama независимо от `LLM_PROVIDER`. Используйте новый путь для HTML-отчёта при диагностике: если анализ завершается ошибкой, старый файл отчёта не перезаписывается.

Если `ollama run qwen3:4b` уже работает в другом окне, оставьте его открытым. В окне с ботом должно появиться сообщение о запуске; для остановки нажмите Ctrl+C. Не публикуйте токен и не коммитьте его в репозиторий.

### 4. Использование

Найдите созданного бота по имени в Telegram, нажмите Start или отправьте `/start`, затем прикрепите договор как файл. После завершения бот вернёт HTML-отчёт. Пока открыт Telegram-бот и включена Ollama, можно отправлять документы; команда `/start` не нужна перед каждым файлом.

Бот открыт для всех пользователей в личных чатах, поэтому любой может использовать память и процессор вашего компьютера. Для личного тестирования поделитесь ссылкой только с теми, кому доверяете; для публичного запуска стоит добавить защиту от злоупотреблений и очередь запросов. Не отключайте ограничение размера файла без дополнительной защиты.

Компьютер и Ollama должны быть запущены для работы бота; long polling обычно не требует открывать входящий порт. Ollama оставляйте доступной только локально.

**Конфиденциальность:** локальная Ollama не отправляет текст договора облачному провайдеру модели. Однако файл, отправленный Telegram-боту, проходит через инфраструктуру Telegram; не используйте такой способ для договоров, если это неприемлемо по требованиям конфиденциальности.
